## Site map
Home / Menu / Matcha Guide / Story / Order / Pickup / Seasonal Editions / FAQ / Contact.

## Visual
High-end tea studio: parchment, near-black, matcha green, subtle silver. Japanese-inspired grid, macro tea imagery, strong whitespace.

## Motion/VFX
Ink/water matcha shader; powder particles; ingredient cards reveal on scroll; 3D cup tilt; smooth section transitions; seasonal hero swaps; scroll enter/exit animation with blur and opacity. Keep WebGL lightweight.

## Functional
Current preorder window; live sold-out state; order deep-link; pickup instructions; matcha profile guide; seasonal archive; Instagram; allergy information; SEO; accessible mobile navigation.

Reconfirm the current order URL, menu, hours and pickup details before deployment.
